# Mega Man X6 Setup Guide

> **Not playable yet.** The disc patch and the game client are not written, so
> there is nothing to install and nothing to connect. This page exists so the
> world passes Archipelago's documentation checks and so the eventual
> instructions have a home. It will be replaced with real setup steps when the
> client ships.

## What will be required

- A Mega Man X6 (USA) disc image, raw 2352-byte `.bin` — the same format the
  Mega Man X5 world uses. You must supply your own; none is distributed.
- BizHawk 2.10 or newer, with the Nymashock PlayStation core.
- A PlayStation BIOS in BizHawk's `Firmware/` folder.
- The Archipelago Mega Man X6 Client, launched from the Archipelago Launcher.

## Generating a seed today

Generation works. Add `Mega Man X6` to your YAML with the options described on
the game info page and generate as normal. The seed will contain no patch file,
so treat the result as a logic test rather than something to play.
